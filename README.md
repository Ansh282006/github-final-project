# Simple Interest Calculator

## Project Description
The Simple Interest Calculator is a simple Bash-based project that calculates interest using the principal amount, annual rate of interest, and time period entered by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input
- Principal amount
- Annual rate of interest (percentage)
- Time period (years)

## Output
The calculated simple interest.

## Technologies Used
- Bash scripting
- Git
- GitHub

## How to Run
Open the terminal in the project directory and execute:

```bash
bash simple-interest.sh
