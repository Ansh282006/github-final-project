# Simple Interest Calculator

A simple Python calculator that computes simple interest using the formula:

SI = (P × R × T) / 100

Where:
- P = Principal amount
- R = Annual interest rate
- T = Time in years

## Example

If P = 1000, R = 5, and T = 2:

SI = (1000 × 5 × 2) / 100 = 100

Total amount = Principal + Simple Interest = 1100

## Features

- Calculates simple interest
- Accepts principal, rate, and time as input
- Displays simple interest and total amount
- Handles invalid number input

## Usage

Run the script and enter the required values when prompted:

```bash
python simple_interest.py
