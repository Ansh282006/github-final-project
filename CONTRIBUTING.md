# Contributing Guidelines

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. Fork the repository to your GitHub account.
2. Clone your fork to your local machine.
3. Create a new branch for your changes.
4. Make your changes and test them.
5. Commit your changes with a clear and descriptive commit message.
6. Push your branch to your GitHub repository.
7. Open a pull request describing your changes.

## Reporting Bugs

When reporting a bug, please include:
- A clear description of the problem.
- Steps to reproduce the issue.
- The expected behavior and the actual behavior.
- Relevant error messages or screenshots, if available.

## Suggesting Enhancements

Suggestions and new ideas are encouraged. Please describe the proposed improvement, its benefits, and any relevant examples.

## Code and Documentation

- Keep changes focused and easy to review.
- Write clear, readable code.
- Update documentation when necessary.
- Test your changes before submitting a pull request.

Thank you for helping improve the Simple Interest Calculator project!
